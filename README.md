# Morrow & Paw

A complete premium pet-shop HTML template in the existing project folder. Built with HTML5, Bootstrap 5.3.8, CSS, and vanilla JavaScript. No dashboard or framework.

## Preview

Open `index.html`, or run:

```sh
npm install
npm start
```

Visit http://127.0.0.1:4173.

## Included

- Two distinct homepages with ten sections each.
- Shop, product details, brands, grooming, journal, about, and contact.
- 404 and coming soon.
- Light/dark themes, persistent RTL, responsive navigation, product search/filter/sort, article search, gallery, tabs, countdown, and accessible form validation.
- Local WebP photography, original AI product and lifestyle imagery, local fonts, Bootstrap, icons, favicon, metadata, structured data, sitemap, and robots.txt.

## Develop and test

The project is organized into:

```text
index.html                  Main homepage
pages/                      Store, services, and information pages
assets/                     CSS, JavaScript, fonts, icons, and images
scripts/                    Build tools and reusable page components
documentation/              Setup guides, asset records, and page manifest
tests/                      Browser checks and reports
  screenshots/              Responsive page captures
  artifacts/reviews/        Visual review images
```


```sh
npm run build
npm test
```

Keep the preview server running for the browser audit. The test defaults to the installed Microsoft Edge on Windows; use `BROWSER_PATH` for another Chromium browser. It checks all specified screen widths and captures page screenshots. Results: `tests/audit-report.json`.

Source content lives in `scripts/build.cjs`. Generated HTML is also directly editable; regeneration overwrites HTML content. Shared design tokens are in `assets/css/style.css`; dark and RTL overrides have separate files.

Readable type and the refined card/button treatments live in `assets/css/premium.css`: body paragraphs are 17px and action labels are 16px. Original page-specific closing sections, testimonial portraits, and the M/P crest are generated by `scripts/premium-components.cjs`. Run `node tests/readability.cjs` to measure paragraph and button sizes across the public pages.

The six inner-page heroes are generated by `scripts/page-heroes.cjs`. Their centered layouts and distinct backgrounds are styled in `assets/css/premium.css`; the shared header height adjusts each hero to fill the first screen. Original hero photographs are recorded in `documentation/hero-assets.json`. Run `node tests/page-heroes.cjs` to verify screen fit, alignment, themes, and RTL.

## Demo boundaries

Forms validate locally but do not send data. Products, prices, brands, ratings, testimonials, and store details are fictional. Product-card Add/Added buttons toggle a cart saved in this browser; the header badge and cart panel reflect selected items. Product image and title links open details or prefilled special-order enquiries. No checkout is included.

Before a real launch, connect form services and replace `example.com`, contact details, social links, business policies, product information, and demo notices. Configure a host-level 404 page. See `documentation/index.html` for instructions.
